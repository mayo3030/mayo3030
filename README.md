## How I approach a product

| Step | Working principle |
|---|---|
| **Frame the decision** | Identify the user, the operational context, and the decision that the interface must make easier. |
| **Build the system** | Establish maintainable client, server, data, and component boundaries appropriate to the problem. |
| **Make it legible** | Shape the first screen, navigation, and documentation so a reviewer can understand the product quickly. |
